# Brady Tool Parser

Парсер каталога интернет-магазина [bradytool.ru](https://bradytool.ru) с выгрузкой в Excel.

## Возможности

- Автоматический обход всех 8 категорий каталога (~13 500 товаров)
- Параллельная загрузка карточек товаров (настраиваемое число потоков)
- Промежуточное сохранение — данные не теряются при сбое
- Фильтрация по категориям
- Корректная обработка ошибок и повторные попытки запросов

## Собираемые данные

| Колонка         | Описание                          |
|-----------------|-----------------------------------|
| Ссылка          | URL страницы товара               |
| Раздел          | Категория каталога                |
| Артикул         | Код товара (SKU)                  |
| Товар           | Полное название                   |
| Описание        | Текст описания                    |
| Цена            | Цена в рублях                     |
| Наличие         | Статус наличия на складе          |
| Производитель   | Бренд                             |
| Фото            | Ссылка на оригинальное изображение|

## Установка

```bash
git clone https://github.com/<username>/bradytool-parser.git
cd bradytool-parser
pip install -r requirements.txt
```

Требуется **Python 3.10+**.

## Использование

```bash
# Полный парсинг всего каталога
python parser_brady.py

# Тестовый запуск (10 товаров)
python parser_brady.py --test

# Указать файл и количество потоков
python parser_brady.py -o catalog.xlsx -w 10

# Парсить только одну категорию (по slug)
python parser_brady.py -c printerny

# Несколько категорий
python parser_brady.py -c printerny -c ribbony

# Подробный вывод (DEBUG)
python parser_brady.py -v
```

### Все параметры

| Флаг              | Описание                                   | По умолчанию             |
|-------------------|--------------------------------------------|--------------------------|
| `--test`          | Обработать только 10 товаров               | —                        |
| `-o`, `--output`  | Имя выходного `.xlsx` файла                | `bradytool_catalog.xlsx` |
| `-w`, `--workers` | Количество параллельных потоков             | `5`                      |
| `-c`, `--category`| Фильтр по категории (название или slug)    | все категории            |
| `--save-every`    | Промежуточное сохранение каждые N товаров   | `200`                    |
| `-v`, `--verbose` | Подробный лог (уровень DEBUG)              | выключен                 |

## Примечания

- Полный парсинг занимает **4–6 часов** (зависит от скорости соединения и числа потоков)
- Промежуточные результаты сохраняются автоматически — можно прервать и открыть `.xlsx`
- При `Ctrl+C` парсер корректно завершается и сохраняет собранные данные
